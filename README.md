Open Fire is a prototype proof-of-concept for an Arcade On-Rails Shooter-type game, heavily inspired by Time Crisis.
The objective is to shoot your way through the arena. Watch out for the "DANGER" shots represented by the glowing RED markers. Those will damage you!

This game was built for a university assignment over 4 weeks using the Unity Engine. It is very short as a result and only has a single prototype/proof-of-concept style level.
